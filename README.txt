EYEPRO OPTICAL WEBSITE
======================
Open index.html in any browser. To publish, upload this whole folder to any web host.

EDITING
- Text: open index.html in any text editor and change the wording.
- Colours/fonts/layout: style.css (see the :root block at the top for brand colours).
- Images: replace any file inside the images/ folder with a new one of the SAME FILE NAME (keep .jpg for photos, .png for logos).
    hero.jpg, modern-outlet.jpg, corporate-cluster.jpg, commitment.jpg, future-plan.jpg, team-group.jpg
    team-shaheen/farheen/dolilla/javed/saniyya.jpg   (portraits, ideally portrait-shaped)
    client-*.png (client logos)   logo.png / logo-white.png / avl-logo.png
- Contact form: opens the visitor's email app addressed to info@eyeproptical.com. See script.js to connect Formspree/Netlify instead.
- Social icons: replace the href="#" links in the footer with your real page URLs.
